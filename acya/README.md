## 🚀 Deploy in 3 Steps (FREE — No coding knowledge needed)

### Step 1 — Create accounts (free)
1. Go to **https://github.com** → Sign up (free)
2. Go to **https://vercel.com** → Sign up with your GitHub account

### Step 2 — Upload to GitHub
1. On GitHub, click the **+** button → **New repository**
2. Name it: `acya-manifesto` → Click **Create repository**
3. Click **uploading an existing file**
4. **Drag the entire `acya` folder contents** into the upload area
5. Click **Commit changes**

### Step 3 — Deploy with Vercel
1. Go to **https://vercel.com/new**
2. Click **Import** next to your `acya-manifesto` repo
3. Click **Deploy** (Vercel auto-detects Next.js — no settings to change)
4. In ~60 seconds you get a live URL like: `https://acya-manifesto.vercel.app`
